Environment Control

Supabase & API Secrets

  • SUPABASE_URL configured
  • SUPABASE_ANON_KEY browser
  • SUPABASE_SERVICE_ROLE_KEY server only
  • SESSION_DATABASE_PATH apps/api/data
  • CORS_ALLOWED_ORIGINS auto + custom

Mirror these variables inside each Netlify site so browsers can talk to the hosted API without leaking privileged keys.
