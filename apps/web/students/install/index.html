Controlled beta

Install SessionSignal in Chrome Developer Mode.

The download extracts into one clearly named SessionSignal folder with a START_HERE guide. You select the whole folder in Chrome—no command line and no setup scripts.

Download beta ZIP Release notes
Beta 0.3.0: the ZIP is generated reproducibly from the extension build output. Advanced users can verify it with the published SHA-256 checksum. If a download is unavailable in a preview deployment, the owner must run npm run package:extension and redeploy the generated artifact.
  1. Download the SessionSignal beta ZIP from this page.
  2. Extract the ZIP. It creates one folder named SessionSignal Beta 0.3.0. Double-click START_HERE.html if you want the instructions beside you.
  3. In Google Chrome, enter chrome://extensions in the address bar and enable Developer mode.
  4. Click Load unpacked and select the entire SessionSignal Beta 0.3.0 folder. Do not select an individual file.
  5. Pin SessionSignal, click its icon, and choose Open Side Panel or Open in New Tab.
Why is extraction required? Chrome does not allow a downloaded ZIP to run directly. This five-step Developer Mode process is the simplest safe beta installation. A future Chrome Web Store release can provide one-click installation.

Updating the beta

Remove the old SessionSignal extension in chrome://extensions, download and extract the new ZIP, then load the newly extracted SessionSignal folder. Unpacked extensions do not update automatically like Chrome Web Store extensions.

Before the session

Confirm Chrome is current, your webcam is available, and the facilitator has given you an active six-character code. Meet, Zoom, or Teams camera access and SessionSignal access are separate; simultaneous access depends on your device and operating system.
