How it works

From local camera frames to facilitator-ready context.

SessionSignal does not host your event. It adds an opt-in numerical signal layer beside the live-session tool you already use.

01

Authenticated session

The facilitator signs in, starts a session, and shares its six-character code.

02

Explicit participant start

The extension validates the code, explains data handling, and requests camera access only after the participant clicks Start.

03

Local analysis

MediaPipe Face Mesh and the existing scoring logic run inside the active extension page.

04

Five-second summary

Frame metrics are reduced to numerical summaries, categories, trends, and event flags.

05

Secure persistence

Supabase validates participant ownership and the active session before saving each packet.

06

Private live update

A database trigger broadcasts the accepted snapshot only to the authorised facilitator channel.

No custom always-on server in the production path.

Supabase Auth provides facilitator and pseudonymous participant identities. PostgreSQL stores sessions and telemetry. Row Level Security enforces ownership. Private Realtime Broadcast delivers accepted events.

Camera frames remain on the participant's device.
