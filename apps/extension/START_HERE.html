Three minutes to get started.

Good news: you do not need to open, move, or understand any of the other files in this folder. Chrome uses them automatically.

  1. Open Chrome and type chrome://extensions into the address bar.
  2. Turn on Developer mode, then click Load unpacked.
  3. Select the whole folder containing this guide. In Chrome, pin SessionSignal Participant Beta and click its icon.

Do not delete files inside this folder. If installation fails, extract the ZIP again and select the newly extracted folder.

SessionSignal asks for camera access only after you join a valid live session and choose Start. Camera frames stay on this device; numerical summaries may be shared with the session facilitator.
